# 🏆 VoteGuide

VoteGuide is an accessible, AI-powered civic assistant that uses Gemini 3 Pro to help voters find polling places, understand ballot measures, and set voting reminders.

## Quick Start
*Note: We commit `package-lock.json` for reproducible builds.*

1. Clone the repo
2. `npm install` (root and in `functions/`)
3. `npm run dev`
